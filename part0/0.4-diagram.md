
sequenceDiagram
participant browser
participant server

    Note over browser: User types a new note and clicks Save

    browser->>server: POST /exampleapp/new_note (note=Hello World)
    activate server
    Note right of server: Server creates a note with the content and current timestamp, then saves it to the notes array
    server-->>browser: HTTP 302 Redirect (Location: /exampleapp/notes)
    deactivate server

    Note over browser: Browser follows redirect and reloads the page

    browser->>server: GET /exampleapp/notes
    activate server
    server-->>browser: HTML document
    deactivate server

    browser->>server: GET /exampleapp/main.css
    activate server
    server-->>browser: CSS file
    deactivate server

    browser->>server: GET /exampleapp/main.js
    activate server
    server-->>browser: JavaScript file
    deactivate server

    Note over browser: Browser executes JavaScript to fetch notes

    browser->>server: GET /exampleapp/data.json
    activate server
    server-->>browser: JSON data including the newly saved note
    deactivate server

    Note over browser: JavaScript callback renders the updated notes list
